# Render Scripted Attributes of Indicated Components

Renders the scripted attributes of indicated components. Generic: an
alias for
[`enscript`](https://bergsmat.github.io/yamlet/reference/enscript.md).

## Usage

``` r
scripted(x, ...)
```

## Arguments

- x:

  object

- ...:

  passed arguments
