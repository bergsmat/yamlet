# Coerce to Yam

Coerce to yam, a precursor to yamlet. Generic, with character method:
[`as_yam.character`](https://bergsmat.github.io/yamlet/reference/as_yam.character.md).

## Usage

``` r
as_yam(x, ...)
```

## Arguments

- x:

  object

- ...:

  passed arguments

## Value

list
