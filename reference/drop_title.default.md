# Drop Title by Default

Drops title by default. To be specific: this is the default method for
the generic function
[`drop_title`](https://bergsmat.github.io/yamlet/reference/drop_title.md),
and it actually does nothing. Individual methods are written for those
classes where 'drop title' behavior is expected.

## Usage

``` r
# Default S3 method
drop_title(x, ...)
```

## Arguments

- x:

  object

- ...:

  ignored

## Value

same as x
