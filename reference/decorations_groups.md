# Recover Groups Decorations

Recovers groups decorations. Generic, with method
[`decorations_groups.data.frame`](https://bergsmat.github.io/yamlet/reference/decorations_groups.data.frame.md)

## Usage

``` r
decorations_groups(x, ...)
```

## Arguments

- x:

  object of dispatch

- ...:

  passed
