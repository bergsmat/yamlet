# Coerce Common Type to Decorated

Coerces common type to decorated. Wrapper for
[`df_ptype2`](https://vctrs.r-lib.org/reference/df_ptype2.html).

## Usage

``` r
dd_ptype2(x, y, ...)
```

## Arguments

- x:

  subclass of data.frame

- y:

  subclass of data.frame

- ...:

  passed arguments

## Value

decorated
