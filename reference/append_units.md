# Append Units

Appends units attribute to label attribute. Generic, with methods
[`append_units.default`](https://bergsmat.github.io/yamlet/reference/append_units.default.md)
and
[`append_units.data.frame`](https://bergsmat.github.io/yamlet/reference/append_units.data.frame.md).
For a more general strategy see
[`modify`](https://bergsmat.github.io/yamlet/reference/modify.md).

## Usage

``` r
append_units(x, ...)
```

## Arguments

- x:

  object

- ...:

  passed arguments
