# Check Something is Parseable as Units by Default

Checks if something is parseable as units. Tests against the udunits
library in units. See
[`as_units`](https://r-quantities.github.io/units/reference/units.html).
See also
[`install_unit`](https://r-quantities.github.io/units/reference/install_unit.html)
for finer control.

## Usage

``` r
# Default S3 method
is_parseable(x, ...)
```

## Arguments

- x:

  character

- ...:

  passed arguments

## Value

logical

## Examples

``` r
is_parseable(c('kg/m2','kg/m^2','kg.m/s2','µg/L'))
#> [1] TRUE TRUE TRUE TRUE
is_parseable('foo')
#> [1] FALSE
library(units)
install_unit('foo')
is_parseable('foo')
#> [1] TRUE
```
