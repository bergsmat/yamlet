# Coerce to Yamlet Storage Format

Coerces to yamlet storage format. Generic, with methods for default,
null, character and list which together implement the yamlet storage
syntax. Always returns length-one character, possibly the empty string.

## Usage

``` r
to_yamlet(x, ...)
```

## Arguments

- x:

  object

- ...:

  ignored

## Value

length-one character
