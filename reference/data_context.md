# Retrieve Data Context

Retrieves data context as 'data.frame'. Generic, with methods
[`data_context.ggplot`](https://bergsmat.github.io/yamlet/reference/data_context.ggplot.md).

## Usage

``` r
data_context(x, ...)
```

## Arguments

- x:

  object of dispatch

- ...:

  ignored

## Value

data.frame
