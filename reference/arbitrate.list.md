# Arbitrate List

Arbitrates two attributes, the first of which is a list. If x has names,
it is cast as namedList and arbitrated thus.

## Usage

``` r
# S3 method for class 'list'
arbitrate(x, y, ...)
```

## Arguments

- x:

  left attribute

- y:

  right attribute

- ...:

  passed arguments

## Value

list
