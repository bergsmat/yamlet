# Reduce by Default to Simplest Sufficient Version

Reduces by default to simplest sufficient version. This is a companion
to
[`parsimonious.list`](https://bergsmat.github.io/yamlet/reference/parsimonious.list.md)
and currently returns an unmodified object.

## Usage

``` r
# Default S3 method
parsimonious(x, ...)
```

## Arguments

- x:

  object for which no specific parsimonious method exists

- ...:

  ignored
