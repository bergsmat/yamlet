# Coerce Data.frame to Decorated

Coerces data.frame to decorated. Wrapper for
[`df_cast`](https://vctrs.r-lib.org/reference/df_ptype2.html).

## Usage

``` r
dd_cast(x, to, ...)
```

## Arguments

- x:

  subclass of data.frame

- to:

  subclass of data.frame

- ...:

  passed arguments

## Value

decorated
