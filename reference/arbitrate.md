# Arbitrate Two Attributes

Arbitrates two attribute sets. Generic, with methods
[`arbitrate.NULL`](https://bergsmat.github.io/yamlet/reference/arbitrate.NULL.md),
[`arbitrate.namedList`](https://bergsmat.github.io/yamlet/reference/arbitrate.namedList.md),
[`arbitrate.list`](https://bergsmat.github.io/yamlet/reference/arbitrate.list.md),
[`arbitrate.default`](https://bergsmat.github.io/yamlet/reference/arbitrate.default.md).

## Usage

``` r
arbitrate(x, y, ...)
```

## Arguments

- x:

  left attribute set

- y:

  right attribute set

- ...:

  passed arguments

## Value

list (of attributes)
