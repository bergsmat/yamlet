**yamlet** is an R package that implements an integrative mechanism for documenting variable attributes 
such as labels, units, and decodes (i.e., factor level descriptors).  An abbreviated coding convention
simplifies capture of the attributes, which then "follow" the data throughout the workflow.  The user
can show/hide the attributes arbitrarily, reducing the work required to properly document figures, tables,
and datasets.  For more detail, see the link below.


[Documentation and examples](https://bergsmat.github.io/yamlet/)
